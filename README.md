A simple Python weather application that fetches real-time weather information using the **WeatherAPI** and announces the weather using Windows Text-to-Speech (SAPI).

## Features

-  Search weather by city name
-  Displays current temperature
-  Shows humidity
-  Displays current weather condition
-  Reads the weather aloud using Windows Speech API

## Technologies Used

- Python 3
- Requests
- python-dotenv
- pywin32
- WeatherAPI
